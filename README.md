# Sell Lemons - kraken

kraken - advanced script, currently one of the best ones.

---

## Features

- **Automation**: Auto-Buy and Auto-Upgrade with customizable speed profiles.
- **Advanced Prestige Engine**:
  - Peak-rate algorithm for **Auto-Rebirth** to maximize investor gains.
  - Automatic **Evolution** and **Ascension/Inversion** triggers with custom thresholds.
- **Worlds Support**: Full feature parity across both World 1 and World 2 instances.
- **Discord Integration & Remote Control (WIP)**:
  - Live farm reporting via Discord webhooks.
  - Real-time command execution (`START_FARM`, `STOP_FARM`, `POTATO_MODE`, `REJOIN`, `SERVER_HOP`).
- **Security & Utility**:
  - Anti AFK.
  - Staff detection radar with automatic Discord `@everyone` pinging.
  - Performance optimization with **Potato Mode** (removes heavy effects, shadows, and textures).
  - Character adjustments (WalkSpeed, JumpPower, Noclip, Fly, Infinite Jump, FOV).

---

## Execution

Load the script directly into your executor. Strong ones recommended for best experience.

---

## Configuration & Keybinds
Default Keybind: Press **K** to toggle the UI interface. You can rebind this under the Settings tab.

Profiles: Configurations auto-save to `kraken_configs/kraken_default.json` in your executor's workspace folder.
